# NetStrike

交互式高并发网络压力测试工具，跨平台（Linux / Windows）。基于 Python 3.8+ 标准库实现，无需 pip 安装任何依赖。

## 免责声明

仅限对已获书面授权的目标进行压力测试。对未授权目标发起攻击所产生的一切后果由使用者自行承担。

## 功能

- 7 种攻击向量：SYN / TCP / UDP / HTTP / HTTPS / DNS / 混合(UDP+TCP)
- 5 档强度：light / normal / heavy / extreme / insane
- 多进程 + 每进程多线程，实时输出 pps / Mbps / 连接数 / 错误率
- TLS 压测：可锁 TLS 1.2 / 1.3，支持 SNI、ALPN、Cipher 套件、Host 头覆盖、连接复用与握手并发上限
- HTTP 响应策略：等待完整响应（数据可信）或发射后不管（纯压带宽），含单条响应超时
- DNS 专项：可随机化查询域名（压递归解析）、可选读取响应、可调响应排空频率
- 源 IP 伪造（SYN / UDP，需 root / 管理员）
- 跨平台抽象：Linux 走 `/proc` 与原始套接字；Windows 走 iphlpapi 与 IP_HDRINCL，并自动开启控制台 ANSI
- 收包统计只取默认网卡，Mbps 更贴近真实出口；单调时钟计时，不受 NTP 校时影响
- 连通性预检（TCP/TLS 与 UDP 分别探测）、错误分类与根因诊断，测试结束输出汇总报告

## 环境要求

- Linux 或 Windows（macOS 可运行但原始套接字向量未做适配）
- Python 3.8+
- 特权：Linux 需 root，Windows 需「以管理员身份运行」才能使用 SYN / UDP 原始包向量；TCP / HTTP / HTTPS / DNS 无需特权
- Linux 建议先执行 `ulimit -n 1048576` 提高 fd 上限

## 快速开始

```bash
# Linux
python3 netstrike.py

# Windows（管理员 CMD/PowerShell）
python netstrike.py
```

全部为交互式问答，无命令行参数。启动后依次输入即可。

## 攻击向量

| 编号 | 向量 | 说明 | 特权 |
|------|------|------|------|
| 1 | SYN 洪水 | 原始套接字灌满目标 SYN 队列形成半连接 | 是 |
| 2 | TCP 洪水 | 并发 connect，耗尽 accept 队列与 fd 表 | 否 |
| 3 | UDP 洪水 | 大包/小包混合，淹没带宽与报文队列 | 是 |
| 4 | HTTP 洪水 | 应用层 GET/POST，keep-alive 长连接复用 | 否 |
| 5 | HTTPS 洪水 | TLS 加密层压测，测握手与解密开销 | 否 |
| 6 | DNS 洪水 | DNS 解析服务器压测，支持随机域名与响应统计 | 否 |
| 7 | 混合向量 | UDP + TCP 同时打击 | 是（UDP 部分） |

## 强度档位

| 档位 | 默认并发 | 默认线程 | 默认负载(字节) | 说明 |
|------|---------|---------|---------------|------|
| light | 100 | 32 | 1024 | 低强度（约 1 万 pps） |
| normal | 1000 | 64 | 1400 | 标准档（约 10 万 pps） |
| heavy | 5000 | 128 | 1400 | 高强度（约 50 万 pps） |
| extreme | 20000 | 256 | 1400 | 极高（约 200 万 pps，需 ≥10Gbps 出口） |
| insane | 50000 | 512 | 1400 | 极限（打满本机，仅限千兆专线靶场） |

## 配置流程

启动后按提示依次输入：

1. 攻击向量（1–7）
2. 目标（支持 `https://host:port/path`、`host:port`、`host`）
3. 目标端口（缺省：HTTPS=443，DNS=53，其他=80）
4. 强度档位（1–5）
5. 持续时间（秒）
6. 工作进程数
7. 包 / 负载大小（字节）
8. 并发数（覆盖档位默认值）；若超出 fd 承载能力，会提示调整，输入 0 表示保持原值
9. HTTP 模式：方法（GET/POST/PUT/HEAD）、请求路径、请求体大小
10. TLS 模式：证书校验、TLS 版本（1.2 / 1.3 / auto）、ALPN、SNI、Host 头覆盖、Cipher 套件、连接复用、握手并发上限
11. 建连 / 握手超时（秒）
12. HTTP 模式：是否等待完整响应；等待时再设单条响应超时（秒）
13. DNS 模式：是否随机化查询域名、是否读取响应；读取时再设每批排空包数
14. SYN / UDP 模式：是否伪造源 IP
15. 确认后开始

## 输出报告

测试结束输出汇总：总发包、总流量、收到数据、建连尝试 / 成功连接数（按向量标注语义）、错误 / 超时数、TLS 握手成功率、平均速率（按实际测量窗口计算）、错误分类与根因诊断。DNS 的「无应答」作为软信号处理，不直接等同于失败。
